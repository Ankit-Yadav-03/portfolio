StreamGuard

Open source

A self-hosted control plane for LLM token streaming. Sits between model and client to stop token production the moment a user disconnects — eliminating silent token burn, unbounded buffer growth, and unattributed cost spikes. Enforces accounting invariants (produced ≥ committed ≥ consumed) and emits per-stream receipts with full lifecycle timestamps, covered by unit and integration tests against a live Ollama backend.

  • Python
  • FastAPI
  • WebSocket
  • Asyncio
  • Ollama
  • Docker
