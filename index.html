NSE Trading Agent

Multi-agent LLM decision system, running in paper trading

Private repo

A multi-agent LLM system for Indian equities (NSE), built from scratch in Python. Eight agents cover data ingestion, technical, fundamental and macro analysis, orchestration, risk, execution and review. They are coordinated by FastAPI, with ChromaDB for RAG memory. Gemini handles inference with a local Ollama fallback, quota-aware call skipping and JSON retries. Risk rules (stop-losses, position and sector limits, earnings blackouts, trading costs) sit outside the LLM.

Status: paper trading on a 5-year, corporate-action-adjusted dataset of 50 stocks. Three baseline strategies failed my pre-set backtest criteria, so there is no proven edge yet. Next: an evaluation harness for the agents and a clean holdout set.

StreamGuard

Self-hosted LLM streaming control plane

Open source

A self-hosted control plane for LLM token streaming. Sits between model and client to halt token production the moment a user disconnects - eliminating silent token burn, unbounded buffer growth, and unattributed cost spikes. Enforces accounting invariants (produced ≥ committed ≥ consumed) and emits per-stream receipts with full lifecycle timestamps, covered by unit and integration tests against a live Ollama backend.
