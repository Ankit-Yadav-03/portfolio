NSE Trading Agent

Private repo

A locally-hosted, multi-agent AI system for Indian equity markets (NSE/BSE). Eight specialized agents - data ingestion, technical analysis, fundamental analysis, macro analysis, orchestration, risk, execution, and review - run as a coordinated pipeline via FastAPI. LLM inference is local-first using Ollama (Qwen 2.5 7B, Llama 3.1 8B) with cloud escalation tiers (NVIDIA NIM, Gemini Flash, Azure GPT-4o) for high-stakes decisions. A ChromaDB vector store backs retrieval-augmented reasoning across market data and news. A single asyncio lock enforces sequential inference on the constrained local GPU, keeping the system stable without external orchestration infrastructure.

StreamGuard

Open source

A self-hosted control plane for LLM token streaming. Sits between model and client to halt token production the moment a user disconnects - eliminating silent token burn, unbounded buffer growth, and unattributed cost spikes. Enforces accounting invariants (produced ≥ committed ≥ consumed) and emits per-stream receipts with full lifecycle timestamps, covered by unit and integration tests against a live Ollama backend.
